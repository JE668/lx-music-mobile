### 修复

- 修复播放条音质徽章看不见的问题：之前徽章文字颜色误用了播放条自身的背景色，导致徽章画出来了却完全不可读。现在改用主色调底 + 主题文字色，任何主题下都清晰可见
- 修复本地文件与下载歌曲不显示音质的问题：这两类歌曲不走在线音质流程，之前不会上报当前播放音质。现在按音频文件后缀补齐，本地 FLAC / APE / WAV 会正确显示 FLAC / APE / WAV
- 修复切歌后音质徽章沿用上上一首歌音质的问题：现在每次开始为新歌曲取播放地址都会先清空旧值

### 新增

- 车机模式新增「驾驶专注播放页」：全屏大图 + 超大触控目标（播放 96dp、切歌 76dp），适配中控屏与驾驶场景
- 车机模式新增「播放时保持屏幕常亮」开关，基于窗口 `FLAG_KEEP_SCREEN_ON` 实现，无需额外权限
- 音质体系扩展：新增 Master / Atmos+ / Atmos / Hi-Res 档位识别与排序
- 新增换源后备策略选择，支持五种模式：同音源更高音质优先、跨音源更高音质优先、综合最优、允许降级、严格不降级

### 优化

- 播放条整体重新设计：封面加大至 56dp 并改为大圆角带阴影，播放/切歌按钮加大至 28dp，顶部改为大圆角上浮，触控更容易
- 冷启动初始化流程并行化：i18n 先行，主题与用户 API 并行，数据层与全局状态并行
- 播放详情页歌词列表渲染性能优化（限制单批渲染条目数）
- 补全繁体中文语言包缺失的 28 个键值，三语言文件对齐
